# ltsaskaita

A LaTeX class for invoices in Lithuanian (*sąskaita faktūra*). It adds up the lines, works out the VAT, and writes the total in words with the correct grammatical forms. It works with pdfLaTeX, XeLaTeX and LuaLaTeX.

See `ltsaskaita-doc.pdf` for the commands and `ltsaskaita-pavyzdys.pdf` for an example.
