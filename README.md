# LaTeX packages in Lithuanian

- [`ltsaskaita`](ltsaskaita): a class for invoices in Lithuanian, with the total in words. Made by [KokybiskaSvetaine.lt](https://kokybiskasvetaine.lt/).
- [`vardadieniai`](vardadieniai): the Lithuanian name day calendar. Full calendar online at [Dovanos su vardu](https://dovanasuvardu.lt/vardadieniai/).

Each folder has its own licence and README.
