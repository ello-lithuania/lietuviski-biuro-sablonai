# vardadieniai

A LaTeX package with the Lithuanian name day calendar (*vardadieniai*) for all 366 days. Use it to add name days to calendars, planners and greeting cards. It works with pdfLaTeX, XeLaTeX and LuaLaTeX.

See `vardadieniai-doc.pdf` for the commands.

Maintainer: Justas Arbatauskis. Home page: <https://dovanasuvardu.lt/vardadieniai/>. Source and issues: <https://github.com/ello-lithuania/latex-lietuviskai>.
